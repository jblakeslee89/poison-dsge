# Adversarial Nowcasting and Monetary Policy

Interactive companion to a New Keynesian DSGE study of data-poisoning attacks on the Federal Reserve's real-time nowcast inputs.

## What this shows

Three sliders (Phillips curve slope κ, consumption habit h, Fed filter weight K_gain) map onto a pre-computed grid of 220 DSGE solutions. Each configuration reports:

- Response of the policy rate, inflation, and output gap to a +1σ attack shock over 16 quarters.
- Welfare loss (standard NK loss function L = var(π) + 0.5·var(ygap)) under attack-on and attack-off conditions.
- Live crossover probability: the minimum perceived attack probability at which the current filter regime is preferred to the naive (K_gain = 1.0) regime.

Three preset scenarios cover the project's main findings:

1. **Memo (toy model, 2025)** — original Spring 2025 calibration. Produces the headline sign-flip.
2. **Realistic (SW posterior)** — empirical Phillips slope, Smets-Wouters habit, modest Fed filtering.
3. **Defended (heavy filter)** — realistic calibration with Fed ignoring raw nowcast signal.

## Methodology

- New Keynesian DSGE solved in Julia (MacroModelling.jl), validated to machine precision against the original Dynare 6.3 implementation.
- Smets-Wouters frictions: price indexation (χ_p = 0.5), consumption habit (h), interest rate smoothing (ρ_i = 0.7).
- Kalman-style perception filter: `gap_perceived = (1 − K) · ρ_p · gap_perceived[-1] + K · (ygap + ν + attack)`.
- 80-quarter welfare loss computed as sum of squared IRF contributions across three shocks.

## Running locally

Requirements: Python 3.10+.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
# open http://127.0.0.1:8050/
```

Production-mode (matches deployment):

```bash
.venv/bin/pip install gunicorn
.venv/bin/gunicorn -b 0.0.0.0:7860 --workers 2 app:server
```

## Deploying to HuggingFace Spaces

This directory is a self-contained HF Space (Docker SDK). To deploy:

```bash
# From the dash_app/ directory
huggingface-cli login                                       # one-time
huggingface-cli repo create --type space --space_sdk docker poison-dsge
git init && git add . && git commit -m "Initial deploy"
git remote add origin https://huggingface.co/spaces/<user>/poison-dsge
git push origin main
```

HF Spaces builds the Docker image automatically from the `Dockerfile` in this directory. The `data/` subfolder containing the pre-computed cache is copied into the image.

## Rebuilding the cache

The cache files in `data/` are generated by the Julia pre-compute script:

```bash
cd ..
julia --project=. scripts/precompute_dash_cache.jl
cp results/dash_cache_*.csv dash_app/data/
```
